# 04 - EDOs PVI (unipaso / multipaso)

- `metodos_pvi.py` - Euler, Taylor, Heun, punto medio, RK4.
- `sistemas_pvi.py` - Sistemas: Lotka-Volterra, oscilador rigido, SIR, cohete.
- `multipaso.py` - AB2/AB3/AB4, AM3, ABM3, estabilidad y frontera.
- `tiro.py` - Metodo del tiro (biseccion/secante) + cohete balistico.
- `diferencias_finitas_1d.py` - Contorno `-u''+q u=f` y no lineal.
- `calor_1d.py` - Calor explicito/implicito/Crank-Nicolson, adveccion-difusion y ondas.
- `estabilidad_multipaso_ejemplo.py`, `control_multipaso.py` - Ejemplos de estabilidad.
