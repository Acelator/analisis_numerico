# 02 - EDP 2D

- `eliptica_parabolica_2d.py` - Eliptica `u - nu Deltau = f` en `Omega=(0,Lx)x(0,Ly)` con Dirichlet y Neumann `du/dn` en bloque `(Nx+1)*(Ny+1)`. Parabolica `u_t - nu Deltau = f` con theta-metodo.
- `no_lineal_2d.py` - Reaccion-difusion `u_t - Deltau + u2 = f` con Picard y Newton.

Dependencias: `numpy`, `scipy.sparse`. Detalles: `../docs/enunciados_resumidos.md#02_edp_2d`
